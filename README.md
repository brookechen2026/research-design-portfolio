# Research & Design Portfolio

Selected research presentations, posters, and interactive prototypes by Xiaoxi Chen, exploring education, accessibility, and human-centered technology.

## AVATAR — Turning Code into Compassion

A research project exploring personalized aging visualizations as a tool for awareness and reflection, developed through the NCSA SPIN program at the University of Illinois Urbana-Champaign under Dr. Deana McDonagh.

My work includes organizing biomedical evidence into a knowledge graph and connecting user profiles with prompts for personalized aging visualizations.

[View research materials](avatar/)

This folder contains presentation and poster materials. Research code is not included.

## ASL Aspire Redesign

A collaborative CI499 design project exploring multilingual accessibility, personalized learning pathways, progress tracking, and motivation for deaf and hard-of-hearing STEM learners.

The design was informed by related research, Universal Design for Learning, and a stakeholder interview.

- [Final presentation](asl-aspire-redesign/ASL%20Aspire%20Redesign%20Final%20Presentation%20%281%29.pdf)
- [Interactive prototype — Figma Make](https://www.figma.com/make/L0fWs0PU39hwpArkY3Epma/Onboarding-and-Language-Selection)

**Team:** Tim Mora, Rachel Aders, and Xiaoxi Chen.

This is a proposed redesign and interactive prototype, rather than a production release of ASL Aspire.

## About This Repository
